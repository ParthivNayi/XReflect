# XReflect

XReflect is a smart mirror project designed to display useful information while maintaining a clean, minimal interface.

## Features

XReflect currently includes:

- Live time and date
- Time-based greetings
- Minimal smart mirror interface
- Camera support

## Planned Features

- Live weather
- News updates
- Daily quotes
- Outfit suggestions
- Voice controls
- AI-powered features

## Built With

- HTML
- CSS
- JavaScript

## Status

XReflect is currently in development.

This is my first GitHub project, and I will continue adding features as I build XReflect.
